НОВОГОДНЯЯ ОСТАНОВКА — БЫСТРЫЙ ЗАПУСК

1. Скачайте файл NewYear_BusStop.ms на свой компьютер.
2. Откройте 3ds Max. Для удобства начните с новой пустой сцены.
3. Выберите Scripting → Run Script и откройте NewYear_BusStop.ms.
4. Дождитесь создания сцены. Сохраните результат через File → Save As в формате .max.

Скрипт добавляет объекты в открытую сцену: он не очищает её, не удаляет
ваши объекты и не сохраняет файлы автоматически.

В сцене: остановка со стеклянными стенками, заснеженной крышей,
новогоднее оформление, подарки, стилизованный Санта, свет и камера.
Внешние модели, шрифты и текстуры не требуются.

Габариты крыши: около 5,02 × 2,23 м; верх крыши на высоте 2,99 м.
Полная высота композиции — около 4,9 м.

ФАЙЛЫ
• NewYear_BusStop.ms — скрипт для создания сцены в 3ds Max.
• preview.png — изображение этой геометрии, отрендеренное в Blender.
• Holiday_BusStop.fbx — запасной вариант импорта в Max через File → Import → Import.
• Holiday_BusStop.blend — версия сцены для Blender.
• sources/build_scene.py — исходный код генератора сцены.

ЧТО ПРОВЕРЕНО
Геометрия и композиция проверены по Blender-версии. FBX экспортирован
и повторно импортирован в Blender: все 1441 геометрический объект сохранены.
Статическая проверка .ms подтвердила индексы граней, массивы, материалы
и преобразования координат. Это не замена запуску в 3ds Max.
Сам 3ds Max в облачной среде недоступен: запуск .ms в Max не проверен.
Скрипт рассчитан на 3ds Max 2020 и новее с максимально простыми
встроенными средствами. Готового файла .max в комплекте нет.

Материалы и освещение в вашем рендерере могут выглядеть иначе, чем
на preview.png: при необходимости отрегулируйте экспозицию и свет.
Санта выполнен как стилизованная фигура, а не фотореалистичная скульптура.

Если Max покажет ошибку, пришлите её текст и версию 3ds Max.
